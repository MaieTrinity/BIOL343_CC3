Question 3: The four numbers differ. Explain which rows each verb keeps, and what that tells you about samples that are in one file but not the other.

Answer: The full verb has the highest number of rows which allows us to infer that it keeps all rows that are found in both datasets. The inner verb has the lowest number of rows which would indicate that it has the most restriction and would only include rows that are common in both datasets. The right and left verbs are in the middle and just indicate which of the datasets will have “priority” in having all their rows saved while only the rows that match in the other dataset are saved. This means for left the first datasets rows are kept and only the common rows in the second are saved and vice versa with right.
